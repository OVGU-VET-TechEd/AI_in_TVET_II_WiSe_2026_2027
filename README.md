## Repository structure

```
AI_in_TVET_II_WiSe_2026_2027/
  00_Organisation/            organisational overview, presentation template
  01_… – 07_…/                per session: Pxx_*.md (LiaScript slides), Pxx_*.html (HTML slides),
                              Sxx_*.md (self-learning unit), Sxx_*_SCORM.zip (SCORM 1.2 for Moodle)
tools/
  build_html.py               Pxx_*.md → Pxx_*.html
  export_scorm.py             Sxx_*.md → Sxx_*_SCORM.zip (LiaScript exporter)
  normalize.py                house-keeping checks for the LiaScript files
edrys/                        Edrys classroom configurations for the live sessions
index.html, assets/           course website (GitHub Pages)
```

Rebuild after changes: `python3 tools/normalize.py && python3 tools/build_html.py && python3 tools/export_scorm.py`
