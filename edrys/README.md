# Edrys Classrooms for the Live Sessions

Each session deck (P01–P07) has an Edrys configuration ([edrys-Lite](https://edrys-labs.github.io) with the module [module-liascript](https://github.com/edrys-labs/module-liascript)). The LiaScript slides run inside it with `classroom: true`: quiz and survey answers of all participants are synchronised and can be evaluated together up front.

## Procedure (lecturer)

1. Click **Create classroom**. Edrys creates a new classroom owned by your browser.
2. Choose **GOTO CLASSROOM** and copy the address (`https://edrys-labs.github.io/?/classroom/…`).
3. In the edrys-Lite start menu, set *write protection* for this classroom so students cannot change the configuration.
4. Give the classroom link to the students (Moodle, QR code on the first slide).

Important: every click on **Create classroom** creates a *new* room. Students only get the classroom link, never the create link. The classroom lives in the browser it was created in – open it in the same browser before the session.

Sessions 2 and 3 are self-learning (🔵); their classrooms are only needed if they are run live.
